# Everything Mod for Minecraft 26.2

**[Download here](https://github.com/nick183cottee-prog/everything-mod-download-/raw/main/EverythingMod-Easy-Install.zip)** (click it and the zip downloads).

The Everything Mod is one Minecraft mod that does the job of about 30 others: it makes the game run faster,
adds a minimap, bigger mountains, handy building tools, a zoom key and lots of small helpers.
Windows only.

## Install (about 5 minutes)

1. **Have Minecraft Java Edition.** Open the Minecraft Launcher, sign in, and play normal Minecraft once
   (just reach the title screen). Then **close Minecraft and the launcher**.
2. **Download** `EverythingMod-Easy-Install.zip` (the **Download here** link above).
3. **Unzip it.** Right-click the zip > **Extract All...** > **Extract**. (Don't run it from inside the zip.)
4. **Double-click `Install`** in the folder that opens.
   - If Windows says *"Windows protected your PC"*, click **More info** > **Run anyway**.
   - If it asks *"Do you want to run this file?"*, click **Run**.
   - A black window shows 3 steps and then **Done!** Press any key to close it.
5. **Play.** Open the Minecraft Launcher. Next to the green **Play** button, pick **Everything Mod**, then press **Play**.
   The first start takes a few minutes while the launcher downloads things. That's normal.

That's it. Your normal Minecraft worlds and settings are not touched: the mod has its own separate saves.
Your resource packs and shader packs are copied over for you (run Install again to copy new ones).

## The first time you play

- The mod checks how strong your PC is and picks good settings by itself.
- While you play it keeps an eye on the frame rate and turns small things down if the game gets slow,
  then back up when it can. You don't need to change anything.
- New worlds get bigger, more dramatic mountains, lakes and volcanoes.

## Keys worth knowing

| Key | What it does |
|---|---|
| **C** (hold) | Zoom in |
| **J** | Open the big map (a minimap shows in the corner) |
| **B** | Save a waypoint where you stand |
| **R** | Sort the chest or inventory you have open |
| **F9** | Show where mobs can spawn (dark spots) |
| **F7** | Everything Mod settings panel |
| **Right Shift** | Building editor (for creative-mode building) |
| **H** | List of building commands |

Any key can be changed in **Options > Controls**.

## Turning parts on or off

On the title screen, click the **Everything Mod** button (top left). Untick anything you don't want.
Some changes need a game restart.

## If something goes wrong

- **"Minecraft Launcher not found"**: install the official launcher from minecraft.net, sign in, play once, close it,
  then run Install again.
- **"Minecraft or its launcher is open"**: close them (check the icons by the clock too), then run Install again.
- **"Could not download Fabric"**: check you're online and try again.
- **No "Everything Mod" in the launcher**: close the launcher completely and open it again.
- **The game is slow**: press **F7** and click **Set up for my PC**, or lower Render Distance in Options > Video Settings.
- Still stuck? Send Nick a photo of the black install window or of the error.

## Updating

Get the new zip, unzip it, and double-click **Install** again. It swaps the old version for the new one.

## Removing it

In the launcher, open **Installations**, click the **...** next to Everything Mod, and choose **Delete**.
To also remove its worlds, delete the folder `%APPDATA%\.minecraft-everything`
(paste that into the File Explorer address bar).
